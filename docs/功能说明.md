# PengPDFView 1.1.1 功能说明

> 本文描述当前发布版本（1.1.1）已经实现并可用的功能，不包含规划中的特性。
> 适用范围：Windows 10/11 x64 桌面环境；单个免安装的可执行文件。

## 1. 产品定位与交付形态

PengPDFView（界面名 **Peng PDF View / Peng PDF 阅读器**）是一个以“轻量”为首要目标的 PDF 阅读器：

- **原生 Win32 界面**：菜单、工具栏、侧边栏、搜索栏、对话框和页面画布全部自绘，不依赖 MFC/Qt/Electron。
- **单文件交付**：`PengPDFView.exe` 约 682 KB，静态链接 C 运行库（`/MT`），无需安装、无需 DLL 或第三方 PDF 库。
- **零第三方 PDF 引擎依赖**：页面栅格化使用 Windows 自带的 `Windows.Data.Pdf`；PDF 文件结构、目录树、书签和文字层由项目自行解析。
- **双语界面**：简体中文 / English 即时切换。
- **只读**：不会修改被打开的 PDF 文件，也不会把书签或设置写回 PDF。

## 2. 启动、文件打开与文档生命周期

### 2.1 打开方式

支持四种打开方式：

1. 菜单 **文件 → 打开** 或快捷键 `Ctrl+O`；
2. 把 PDF 文件拖放到主窗口任意位置（同时拖入多个文件时取第一个）；
3. 启动时通过命令行传入文件路径，例如：
   `PengPDFView.exe "D:\docs\manual.pdf"`；
4. **文件 → 最近打开** 中的历史文档（最多 8 个）。

### 2.2 文档行为

- 同一窗口一次只阅读一个文档；打开新文档会先关闭当前文档。
- 打开时会先解析文件结构（目录、元数据），再启动后台渲染；目录和窗口标题通常早于第一页位图出现。
- 窗口标题格式为 `文档标题 - Peng PDF View`；优先使用 PDF 元数据中的标题，没有时使用文件名（不含扩展名）。
- 打开失败会弹出本地化错误提示，并回到“未打开文档”的空状态。
- 不限制同时运行多个程序实例；每个实例独立管理自己的文档和窗口。

### 2.3 打开失败与错误提示

以下情况会显示明确的错误对话框：

| 情况 | 提示 |
| --- | --- |
| 文件不存在 | “文件不存在。” |
| 文件超过 1 GiB | 直接拒绝读取 |
| PDF 受密码保护 | “该文档受密码保护，无法打开。” |
| 文件不是有效 PDF | “该文件不是有效的 PDF 文档。” |
| 文件访问被拒绝 | “无法访问该文件。” |
| PDF 引擎无法打开 | “PDF 引擎无法打开该文档。” |
| 文档没有页面 | “该文档不包含任何页面。” |

结构解析失败但 Windows 引擎仍能打开时，阅读和渲染继续可用，只是目录可能为空；这类情况会写入诊断日志。

## 3. 主界面布局

主窗口自上而下分为：

1. **菜单栏**：文件、编辑、视图、转到、书签、设置、帮助。
2. **工具栏**：侧边栏开关、打开、上一页、下一页、页码徽标、缩小、缩放百分比、放大、适合宽度、适合页面、书签星标、设置。
3. **内容区**：
   - 左侧为可显示/隐藏的**目录 / 书签侧边栏**；
   - 中间为**连续页面画布**；
   - 画布右上角浮动**搜索栏**（按 `Ctrl+F` 显示）。
4. **状态栏**：左侧显示当前文档标题与章节数（或工具栏按钮提示），右侧显示“第 X 页，共 Y 页”和当前缩放百分比。

窗口默认约 1240×900 像素；最小尺寸为 920×620（DIP，会按 DPI 换算）；会记住上次的普通窗口位置、大小以及是否最大化。侧边栏宽度也会记住。

## 4. 阅读与页面导航

### 4.1 连续页面视图

- 页面按文档顺序**纵向连续排列**，页与页之间保留间距，页面水平居中。
- 支持混合页面尺寸；缩放基准取文档中最大的页面，避免翻页时缩放比例跳动。
- 页面下方有轻微阴影和 1 像素边框，与画布背景区分。
- 当前页由**视口中心**所在的页面决定，用于状态栏、侧边栏当前章节高亮和书签操作。
- 页面位图按可见范围异步渲染；未渲染完成的页面显示“正在渲染页面...”占位。

### 4.2 工具栏

| 控件 | 行为 |
| --- | --- |
| 侧边栏按钮 | 显示 / 隐藏侧边栏（同 `F4`），激活时高亮 |
| 打开按钮 | 打开 PDF 文件对话框 |
| 上一页 / 下一页 | 按整页跳转；在第一页/最后一页时对应按钮禁用，不循环 |
| 页码徽标 | 显示“当前页 / 总页数”，点击打开“跳转到页面”对话框 |
| 缩小 / 放大 | 按 10% 步长缩放（实际为 ×1.1 / ÷1.1） |
| 缩放百分比 | 只读显示当前缩放比例，点击不响应 |
| 适合宽度 / 适合页面 | 切换缩放模式；当前模式以强调色显示 |
| 书签星标 | 为当前页添加 / 取消书签；已加书签时为实心星 |
| 设置按钮 | 打开设置对话框（固定在工具栏最右侧） |

### 4.3 鼠标与滚动

- **滚轮**：垂直滚动，每档约 80 DIP；
- **Shift + 滚轮**：水平滚动，每档约 90 DIP；
- **Ctrl + 滚轮**：以鼠标位置为锚点缩放；
- **鼠标中键拖拽**：平移页面（左键用于文本选择）；
- **滚动条**：悬浮式细滚动条，可拖拽滑块；点击滑块外的轨道按视口高度的 80% 翻页；
- 页面区域鼠标为 I 形光标，滚动条区域为手形光标，中键拖拽时为移动光标。

### 4.4 键盘导航

| 按键 | 行为 |
| --- | --- |
| `PgUp` / `PgDn` | 上一页 / 下一页 |
| `Home` / `End` | 第一页 / 最后一页 |
| `↑` / `↓` / `←` / `→` | 画布滚动 64 DIP |
| `Ctrl+G` | 打开“跳转到页面”对话框 |

“跳转到页面”对话框只接受数字，页码从 1 开始；超出范围会显示错误并保持对话框打开，`Enter` 确认、`Esc` 取消。

## 5. 缩放

- 缩放范围：**15% – 800%**。
- 缩放模式：
  - **适合宽度**：页面宽度贴合画布可用宽度；
  - **适合页面**：整页（宽和高）都放入画布；
  - **实际大小**：100%；
  - **自定义**：通过按钮、快捷键或 `Ctrl+滚轮` 得到的比例。
- 每次缩放会保持视口中心的内容位置，`Ctrl+滚轮` 则保持鼠标下的内容位置。
- 改变窗口大小或切换 DPI 时，适合宽度/适合页面会重新计算，工具栏和状态栏同步更新百分比。
- 缩放后会按新的物理像素宽度重新渲染页面；最大渲染宽度限制为 6000 像素。

## 6. 目录（章节大纲）侧边栏

侧边栏包含两个标签页：**目录** 和 **书签**。

### 6.1 目录标签页

- 解析 PDF 内部的 `/Outlines` 书签树，按层级缩进展示章节标题。
- 初始展开/折叠状态参考 PDF 的 `/Count` 正负号。
- 带子节点的行显示展开三角：
  - 点击三角展开 / 折叠；
  - 点击标题跳转到目标页。
- 支持 `/Dest` 数组、`/A << /S /GoTo >>` 动作以及 `/Names /Dests` 命名目标。
- 阅读时自动高亮包含当前页的章节，并在必要时把该行滚动到可见区域。
- 长目录只绘制可见行；滚动条、滚轮和键盘都可滚动。
- 文档没有目录时显示“此文档没有目录。”。

### 6.2 侧边栏交互

- `F4` 或工具栏按钮显示 / 隐藏。
- 拖动侧边栏右缘的分隔条调整宽度（约 180–520 DIP），宽度会持久化。
- 目录与书签标签页切换时，滚动位置回到顶部。
- 侧边栏获得焦点后，`↑`/`↓` 可滚动列表；滚轮每档滚动 3 行。

## 7. 用户书签

- 书签与 PDF 内部的目录是两套独立数据，按文档分别保存。
- 添加入口：
  - 工具栏星标；
  - `Ctrl+D`；
  - 菜单 **书签 → 添加书签**。
- `Ctrl+D` 是切换语义：当前页已有书签则取消，没有则添加。
- `Ctrl+Shift+D` 或菜单 **书签 → 删除书签** 删除当前页书签。
- 书签标题在添加时取“从当前页开始的目录条目标题”；如果没有匹配条目，则使用本地化的“第 N 页”。
- 书签列表按页码排序，重复添加同一页会被忽略。
- 侧边栏“书签”标签页展示当前文档的书签；右键某一行可删除。
- 添加/删除后立即写入磁盘，不需要手动保存；PDF 文件本身不会被修改。
- 书签按规范化后的文档绝对路径分组，因此同一文件即使从最近列表、拖放或命令行打开，书签仍然一致。

## 8. 全文搜索

### 8.1 打开与输入

- `Ctrl+F` 或菜单 **编辑 → 查找** 打开画布右上角的浮动搜索栏。
- 若打开搜索前已选中**单行文字**（不超过 120 个字符），会自动填入搜索框并全选；下一次键入会替换它。
- 输入后等待约 **250 ms** 没有新按键才开始搜索；继续输入会取消旧查询并重新开始。
- 搜索框最多输入 256 个字符；支持中文、英文和数字。
- 搜索栏右侧显示状态：
  - “正在搜索...”；
  - “没有找到结果”（错误色）；
  - “第 N 个，共 M 个”。

### 8.2 匹配规则

- **忽略大小写**。
- **空白归一化**：连续空格、制表符、换行都按一个空格处理；查询首尾空白被忽略。
- **跨行匹配**：PDF 中分行的句子可以作为一个查询命中。
- **缺失空格推断**：很多 PDF 逐词定位、不写空格字符，搜索索引会根据字形间距自动补空格。
- 只搜索当前文档，从第一页开始遍历到最后一页，与当前阅读位置无关。
- 每个页面最多保留 2000 个命中，避免极端文档拖垮 UI。
- 搜索在独立工作线程中逐页执行，边搜边显示；开始新查询会取消旧查询，迟到结果会被丢弃。

### 8.3 命中导航与高亮

- 命中文字以**橙色**强调当前命中，其余命中为**黄色**，均按视觉行合并为高亮矩形。
- 第一个命中出现时自动滚动到该位置（约视口三分之一处）。
- `Enter` / 点击“下一个”按钮：下一个命中，到末尾后回到第一个；
- `Shift+Enter` / 点击“上一个”按钮：上一个命中，到开头后回到最后一个；
- 点击搜索栏的关闭按钮或按 `Esc`：关闭搜索栏、取消后台搜索并清除所有高亮；
- 关闭搜索不会清除文本选择，复制仍然可用。

### 8.4 已知边界

- 扫描版 PDF 没有文字层，搜索不到结果，这是文档本身决定的，不是搜索故障。
- 暂不支持正则表达式、全词匹配、替换、区分大小写选项。
- 搜索只覆盖文字层；图片中的文字不会被识别（无 OCR）。

## 9. 文本选择与复制

### 9.1 选择

- 在页面上**按住左键拖拽**选择文字。
- **双击**选择光标下的一个单词。
- 单击（没有拖动）会清除已有选择。
- 选择高亮为半透明蓝色，按视觉行分块绘制。
- 选择按**阅读顺序**（自上而下、自左而右）组织，而不是 PDF 内容流的绘制顺序；因此目录页等“先画标题、后画页码”的页面也能正确选择。
- 拖到行尾会停留在当前行，不会跳到相邻行。
- 选择**一次只覆盖一页**，跨页选择尚未实现。
- 空白页面（扫描页）没有可选择的文字。

### 9.2 复制

- `Ctrl+C` 或菜单 **编辑 → 复制** 把选中文本复制到剪贴板（`CF_UNICODETEXT`）。
- 复制的是纯文本；换行和缺失的空格会根据字形几何自动重建，粘贴到其他应用时保持可读。
- 没有选择时“复制”菜单项为灰色不可用。
- `Esc` 清除选择（若搜索栏已打开，`Esc` 优先关闭搜索栏）。
- 关闭搜索栏不会影响已有选择。

## 10. 语言与设置

### 10.1 语言

- 支持 **简体中文** 与 **English**。
- 首次启动且没有保存语言偏好时，跟随 Windows 显示语言：主语言为中文则使用中文，否则使用英文。
- 切换方式：
  - 菜单 **设置 → 语言**；
  - 设置对话框中的“语言”选项。
- 切换后立即更新菜单、工具栏提示、侧边栏、搜索栏、状态栏、对话框和错误提示，并持久化保存。
- 中文界面使用 Microsoft YaHei UI，英文界面使用 Segoe UI。
- 设置对话框内切换语言是“预览”行为：取消对话框会恢复打开前的语言。

### 10.2 设置对话框

`Ctrl+,` 或菜单 **设置 → 首选项** 打开，包含：

| 设置项 | 取值 | 说明 |
| --- | --- | --- |
| 语言 | English / 简体中文 | 即时预览，确定后保存 |
| 默认缩放 | 适合宽度 / 适合页面 / 实际大小 | 确定后立即应用到当前文档并作为后续默认 |
| 打开文档时显示侧边栏 | 勾选 / 不勾选 | 同时影响当前窗口和后续打开 |

设置对话框中不提供主题切换；当前版本只有浅色主题。

### 10.3 自动记忆的状态

以下状态会写入 `settings.ini`，下次启动恢复：

- 窗口普通状态下的位置、大小、是否最大化；
- 侧边栏是否可见、宽度；
- 默认缩放模式与自定义比例；
- 界面语言；
- 最近打开文件列表（最多 8 个，最近的在最前）。

“文件 → 最近打开”只列出当前仍存在的文件；不存在的条目会被跳过（但不会主动从配置中删除）。

## 12. 渲染、文字层与性能特性

这些是用户可感知的功能行为，不是内部实现细节的全部：

### 12.1 页面渲染

- 使用 Windows 自带的 `Windows.Data.Pdf` 引擎栅格化，保证中文、嵌入字体、透明度和图片的显示质量。
- 页面按白色纸张背景渲染，避免透明区域透出画布颜色。
- 在独立 MTA 工作线程中渲染，UI 不阻塞。
- 可见页面优先；重复请求合并；缩放或关闭文档时取消过期请求。
- 页面位图缓存：最多 12 页，同时受 192 MB 字节预算约束；始终保留当前页。
- 单页最大渲染宽度 6000 像素，防止异常缩放导致超大位图。

### 12.2 文字层与搜索

- 自行解析页面内容流，支持文本矩阵、字距/词距/水平缩放、Form XObject 和字体编码。
- 字符到 Unicode 的映射优先使用字体的 ToUnicode CMap，简单字体回退到 WinAnsi/MacRoman/Standard 与 `/Differences`。
- 字宽来自 `/Widths`、`/W`、`/DW`、`/MissingWidth` 或 Type3 `/FontMatrix`。
- 文字坐标按 CropBox 归一化并按页面 `/Rotate` 旋转，与页面位图对齐。
- 搜索索引按页构建，结果映射回字形范围，再按行合并高亮矩形。
- 文字页缓存最多 64 页，按需提取。

### 12.3 重绘与响应

- 画布使用持久后备位图和脏矩形绘制；选区变化、搜索高亮、单页渲染完成只重绘受影响页面。
- 可见页范围通过二分查找确定，滚动、绘制和鼠标命中不随总页数线性增长。
- 搜索命中按页追加，只失效新增高亮的页面。
- 参考数据（222 页英文手册，i5 级桌面 CPU）：
  - 结构解析约 14 ms；
  - 全书文字提取约 103–106 ms；
  - 全文搜索核心约 2–3 ms；
  - 端到端搜索（含工作线程调度与 UI）约 110 ms；
  - 关闭窗口约 60 ms（清空待渲染队列后）。

## 13. 数据文件与隐私

程序只在用户配置目录下写入三个文件：

```
%APPDATA%\PengPDFView\settings.ini      窗口、语言、缩放、侧边栏、最近文件
%APPDATA%\PengPDFView\bookmarks.tsv     按文档保存的书签（UTF-8）
%APPDATA%\PengPDFView\pengpdfview.log   诊断日志（自动截断）
```

- 不写入注册表，不创建安装目录，不修改 PDF 文件。
- 不联网、不上传文档、不包含遥测。
- 删除 `%APPDATA%\PengPDFView` 即可恢复出厂设置（会丢失书签、最近列表和窗口布局）。

## 14. 适用场景

适合：

- 日常阅读技术手册、规范、论文、报告；
- 需要快速查看 PDF 自带目录并跳转的文档；
- 需要全文搜索和复制文字的文档；
- 希望使用单文件、免安装、无第三方运行库的轻量阅读器的环境；
- 中英文混合的阅读场景。

不适合：

- 需要批注、填写表单、签名、打印、页面管理（插入/删除/旋转）的编辑型工作流；
- 需要 OCR 的扫描件；
- 需要密码解锁的加密 PDF；
- 需要多标签页、多文档并排或书籍库管理的重度场景。

## 15. 已知限制

1. **加密 PDF**：不支持输入密码，受密码保护的文档会直接提示无法打开。
2. **注释 / 表单 / 签名 / 打印**：不支持添加注释、交互式表单填写、数字签名与打印；PDF 中已有的表单外观仍会作为页面内容正常显示。
3. **手动旋转页面**：未提供 UI；PDF 自带的 `/Rotate` 会正常显示。
4. **选择范围**：一次只能选择一页，跨页选择未实现。
5. **扫描件**：没有文字层，搜索无结果、无法选择；不支持 OCR。
6. **字体覆盖**：少数 CID 字体若既没有 ToUnicode、又使用非 Identity 编码，文字可能无法还原或宽度偏移。
7. **目录编码**：非标准的自定义字符串编码可能显示为占位字符。
8. **平台**：仅 Windows（依赖 Win32、WIC 和 `Windows.Data.Pdf`）。
9. **内存**：整个 PDF 会读入内存，超过 1 GiB 的文件会被拒绝；超大页面渲染受 6000 像素宽度限制。
10. **界面**：只有浅色主题；无标签页/多文档同窗；不支持全屏演示模式。
11. **搜索选项**：不支持正则、全词匹配、区分大小写、替换；单页命中上限 2000。
12. **窗口位置恢复**：位于主显示器左侧的负坐标窗口，重启后可能回到默认位置（当前实现把负坐标视为“未保存”）。
13. **画布滚轮**：按整档滚动，高精度触控板的小于 1 档的增量在画布上可能被忽略（侧边栏已做累计处理）。
